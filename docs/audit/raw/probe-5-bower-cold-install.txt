probe-5 -- cold Bower install and the git:// transport, 2026-11-05
================================================================================
The question probe-4 could not answer: `bower install` inside `npm run deps` was a no-op,
because omega-web/bower_components was already installed. This probe removes that directory
(kept, not deleted) and installs again, with and without the transport rewrite
.github/workflows/verify.yml configures on the runner. omega-web/bower.json declares:

    37:    "angular-spectrum-colorpicker": "git://github.com/suziwen/angular-spectrum-colorpicker.git#main",
    43:    "zero-dependencies": "git://github.com/zero-peak/zero-dependencies.git#main",

THE HEADLINE: the string `git://` occurs zero times in the whole capture. Bower rewrites the
declared endpoint to https://github.com/<owner>/<repo>.git before it shells out to git, so the
dead transport in bower.json is never handed to git at all. Both deps resolved to the same
commits the https pre-check reports (4de5f14a04, e22ff9184a). A cold install therefore
succeeds on this host WITHOUT any rewrite -- which is what the runner will also do.
